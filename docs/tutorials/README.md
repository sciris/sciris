# Tutorials

These tutorials walk through how to use Sciris. They are available online at https://docs.sciris.org.

The tutorials are [Quarto](https://quarto.org) documents. To explore them interactively, you can run them locally with Jupyter (run `jupyter lab` in this folder), as long as `jupytext` is installed. You can also run them through the [Quarto extension](https://marketplace.visualstudio.com/items?itemName=quarto.quarto) for VS Code, or via [Positron](https://posit.co/products/ide/positron/). Finally, you can convert them to Jupyter notebooks by running `./convert_notebooks`.
